Installation Guide

## Requirements

• Visual Studio Code
• Live Server Extension
• Modern Web Browser

## Installation

1. Download the ZIP file.
2. Extract the project.
3. Open the project in VS Code.
4. Install Live Server.
5. Open index.html with Live Server.

## Customization

• Change Website Name → index.html
• Change Images → images/
• Change Colors → css/style.css
• Change Contact Information → contact.html
