# 🏆 EliteSports Pro

## 🇺🇸 English

### Professional Sports Center Website

EliteSports Pro is a modern and responsive website designed for sports clubs, gyms, fitness centers, football academies, swimming academies, and martial arts centers.

### Features

- Modern & Premium UI
- Fully Responsive Design
- Fast Loading Speed
- Gallery Page
- Contact Page
- Success Page
- Clean HTML, CSS & JavaScript Code
- SEO Friendly
- Easy to Customize
- Well Organized Project Structure

### Technologies

- HTML5
- CSS3
- JavaScript (ES6)

### Project Structure

```
EliteSports Pro/
│
├── index.html
├── gallery.html
├── contact.html
├── success.html
├── css/
├── javascript/
├── images/
└── documentation/
```

### Installation

1. Download the project.
2. Open it using VS Code.
3. Run with Live Server.
4. Customize the content.
